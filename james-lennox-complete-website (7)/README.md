# James Lennox — NFO1005 portfolio website

Built by adapting the supplied `module3_2_marge_start` Bootstrap multipage university template. The original demo pages, images and résumé have been replaced with James Lennox cricket content. Uses Bootstrap 5.3, Bootstrap Icons, Oswald and Montserrat, custom CSS, a Bootstrap modal, responsive navigation and an accessible mailto form.

## Site map
- `index.html` — introduction and highlights
- `about.html` — background and coaching philosophy
- `resume.html` — experience, education, skills and PDF download
- `portfolio.html` — playing highlight and explicitly labelled proposed coaching projects, with interactive modals
- `contact.html` — email, social profile and mailto form

## Local preview
Open `index.html` in Chrome or Firefox with an internet connection (Bootstrap, icons and Google Fonts are CDN-hosted). For more reliable testing, use VS Code Live Server.

## Publish to GitHub Pages
Create a public repository; upload the **contents** of this folder to the repository root; in Settings > Pages select Deploy from a branch, `main`, `/ (root)`; wait for the generated site URL; open all pages and test all links. Replace the résumé's placeholder portfolio URL when known.
