# NFO1005 Assessment 3 — design and UX documentation

## Concept and audience
James Lennox is an aspiring cricket coach and Penrith Cricket Club player. Intended audiences are prospective coaching mentors, sporting organisations and future employers. The main message is: “Building better cricketers. Building better people.”

## Sitemap
Home → About / Résumé / Portfolio / Contact. The primary navigation is repeated on every page; footer links offer a second navigation technique. The homepage links directly to the About and Portfolio pages.

## Design system
Source: provided Marge Simpson Bootstrap starter. Font pairing: Oswald for headings and Montserrat for body text (Google Fonts). Palette: deep cricket green #123C30, secondary green #1E5948, gold #D8B66C, ivory #F7F5EF, ink #20332D. **Proposed harmony:** analogous greens with contrasting warm gold accent. Adobe Color documentation and colour-blindness simulation remain to be completed in Adobe Color. Buttons use a distinct shape and label in addition to colour.

## Interaction
Bootstrap modal details on three portfolio items. A labelled contact form validates required fields and opens an email draft. The form does not send data to a server.

## UX test plan (not yet performed)
Recruit two different people. Ask each to: (1) locate James’s 2023–24 bowling figures, (2) download his résumé, (3) open the junior coaching concept, (4) find his email address, (5) use the site on a narrow mobile viewport. Ask for feedback on navigation, readability, accessibility and visual design. Record task completion, problems, quotes and recommended fixes.
